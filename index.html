1Estructuras de datos

Por qué necesitamos guardar muchos datos bajo un mismo nombre.

Un problema: guardar 40 notas

Un profesor necesita guardar las 40 notas de su curso y calcular el promedio. Con lo que sabemos hasta ahora… ¿creamos 40 variables?

nota1 = float(input("Nota 1: "))
nota2 = float(input("Nota 2: "))
nota3 = float(input("Nota 3: "))
...
nota40 = float(input("Nota 40: "))
promedio = (nota1 + nota2 + nota3
            + ... + nota40) / 40

¿40 variables?

  • El código es largo y repetitivo.
  • No podemos recorrer nota1, nota2, … con un for.
  • Buscar la nota más alta requeriría comparar las 40 variables una por una.
  • Si el curso tiene 41 estudiantes, hay que cambiar el programa.
Necesitamos guardar muchos datos bajo un mismo nombre

¿Qué es una estructura de datos?

Una estructura de datos es una forma de organizar y almacenar varios datos en la memoria bajo un solo nombre, para poder acceder a ellos y procesarlos fácilmente.

  • Partiremos por la más simple: el arreglo. Con él, las 40 notas se recorren con un for.

¿Qué es un arreglo?

Un arreglo es una estructura de datos que almacena una colección de elementos, a los que se accede mediante un índice que indica su posición.

  • Sus elementos se guardan uno a continuación del otro.
  • Tiene un tamaño fijo: se define al crearlo y no cambia.
  • El primer índice es 0 y el último es tamaño − 1.
  • Normalmente todos sus elementos son del mismo tipo.

Arreglo de tamaño 5

Índices: 0, 1, 2, 3, 4

¿Cómo lo trabajaremos en Python?

Usaremos listas para simular arreglos, pero respetando un tamaño constante: si definimos a = [0, 0, 0, 0], su tamaño siempre será 4.

Tipos de arreglos

Vector · 1 dimensión

Un solo índice: v[i]

Matriz · 2 dimensiones

Dos índices: m[f][c]

Tensor · 3 o más dimensiones

Tres o más índices: t[i][j][k]

En este curso trabajaremos con vectores y matrices. El tensor solo lo mencionamos: es la generalización a más dimensiones.

2Vectores

Arreglos de una dimensión.

Creación

Un vector se crea escribiendo sus elementos entre corchetes. Dos formas habituales:

1. Con valores conocidos

2. Inicializado y llenado por el usuario

  • El tamaño queda fijo al crearlo: v siempre tendrá 5 posiciones.
  • Luego reemplazamos los valores por índice, nunca agregamos.

Acceso

Cada elemento se accede con el nombre del vector y su índice entre corchetes: v[indice]. El índice va desde 0 hasta len(v) − 1.

¡Cuidado con el índice!

  • v[4] no existe en un vector de tamaño 4: Python lanza IndexError.
  • El último elemento siempre es v[len(v) - 1].

La función len

len(v) entrega la cantidad de elementos del vector, es decir, su tamaño. Como nuestros vectores tienen tamaño fijo, len(v) siempre devuelve el mismo valor.

¿Para qué lo usamos?

  • Saber cuántas veces recorrer: range(len(v)).
  • Obtener el último índice: len(v) - 1.

Despliegue

Desplegar es mostrar el contenido del vector. Podemos hacerlo completo o elemento por elemento.

3Recorrido de un vector

Visitar cada posición, de la primera a la última.

Recorrer un vector es visitar cada una de sus posiciones, de la primera a la última. Se hace con un for cuyo índice i toma los valores de range(len(v)).

for i in range(len(v)):
    # trabajar con v[i]

¿Por qué range(len(v))?

  • len(v) es 4, entonces range(4) genera 0, 1, 2, 3: exactamente los índices válidos.
  • Si el vector cambia de tamaño en otro programa, el ciclo se adapta sin modificar el código.

Ruteo: recorrido de un vector

Avanza paso a paso: i comienza en 0, se muestra v[0] que vale 4; luego i avanza a 1, 2 y 3 (la última posición) y el range termina.

Suma y promedio

Para sumar los elementos usamos un acumulador: comienza en 0 y en cada iteración le sumamos v[i]. El promedio es la suma dividida por la cantidad de elementos. Al terminar: suma = 22 y promedio = 22 / 4 = 5.5.

Máximo y mínimo

Partimos suponiendo que el primer elemento es el mayor y el menor. Luego recorremos desde la posición 1 y actualizamos cuando encontramos un valor más grande o más pequeño.

¿Por qué v[0] y no −1?

  • Si todos los valores fueran negativos, mayor = -1 daría un resultado incorrecto.
  • v[0] es un valor real del vector, así que siempre es un buen punto de partida.
  • Para saber dónde está el mayor, guardamos también su índice: pos_mayor = i.

Resultado: mayor = 9 (posición 1) y menor = 2 (posición 2).

4Búsquedas en vectores

Determinar si un valor está en el vector y, si está, en qué posición.

Búsqueda secuencial

Revisa uno por uno, desde el inicio.

¿Está el 21? 12, 5, 8 y en el 4° intento: 21. Sirve para cualquier vector, ordenado o no.

Búsqueda binaria

Divide por la mitad un vector ordenado.

¿Está el 40? El medio es 18 y 18 < 40: se descarta la izquierda. Mucho más rápida, pero exige que el vector esté ordenado.

Búsqueda secuencial

Revisa los elementos uno por uno, desde el inicio, hasta encontrar el valor buscado o llegar al final. Funciona aunque el vector no esté ordenado.

  • pos = -1 funciona como bandera: −1 significa «no encontrado», porque no es un índice válido.
  • Al encontrarlo guardamos el índice y salimos con break.
  • En el peor caso revisa todos los elementos.

En i = 0, i = 1 e i = 2 la comparación es falsa y se continúa; en i = 3, 21 == 21 es verdadero: pos = 3 y break termina el ciclo.

Resolución

Búsqueda binaria

Requiere un vector ordenado. Compara el valor buscado con el elemento del medio: si no es, descarta la mitad donde no puede estar y repite con la otra.

  • izq y der delimitan la zona donde aún puede estar el valor.
  • // es división entera: el medio siempre es un índice válido.
  • Si v[medio] es menor, el valor está a la derecha; si es mayor, a la izquierda.
  • Si izq supera a der, el valor no está.

Paso 1: (0 + 7) // 2 = 3, v[3] = 18 es menor que 40, entonces izq = 4. Paso 2: (4 + 7) // 2 = 5, v[5] = 31 es menor, entonces izq = 6. Paso 3: (6 + 7) // 2 = 6, v[6] = 40 es igual al buscado: pos = 6. ¡Solo 3 comparaciones!

5Ordenamiento

Burbuja y selección, con tamaño fijo.

Intercambio de dos posiciones

Ambos ordenamientos necesitan intercambiar dos elementos. Si hacemos v[0] = v[1] perdemos el valor original, por eso usamos una variable auxiliar: v = [5, 1] pasa a ser v = [1, 5].

Ordenamiento burbuja

Compara pares de elementos vecinos y los intercambia si están en el orden incorrecto. En cada pasada, el mayor de la zona sin ordenar «sube» hasta el final, como una burbuja.

  • i cuenta las pasadas: se necesitan n − 1.
  • j recorre los pares vecinos (v[j], v[j + 1]).
  • Cada pasada deja un elemento fijo al final, por eso el for de j llega hasta n - 1 - i.
  • Para ordenar de mayor a menor basta con cambiar > por <.

Primera pasada

Pasadas 2, 3 y 4

Ordenamiento por selección

En cada pasada selecciona el menor de la zona sin ordenar y lo intercambia con la primera posición de esa zona. Así el vector se ordena de izquierda a derecha.

  • El for interno es el algoritmo del menor, pero guarda la posición y no el valor.
  • Hace un solo intercambio por pasada (burbuja puede hacer muchos).
  • v[i] es el lugar donde debe quedar el menor encontrado.

Azul: posición i · Magenta: menor encontrado · Oscuro: ya ordenado.

6Matrices

Arreglos de dos dimensiones.

¿Qué es una matriz?

Una matriz es un arreglo de dos dimensiones: sus elementos se organizan en filas (horizontales) y columnas (verticales). Cada elemento se ubica con dos índices.

  • m[f][c]: primero la fila, después la columna.
  • La fila 1 (azul) es [3, 5, 6, 2].
  • m[1][2] (magenta) vale 6.
  • Esta matriz es de 3 × 4: 3 filas y 4 columnas.
  • En Python es una lista de listas: cada fila es un vector.

Creación de matrices

Con valores conocidos

Tamaño: filas = len(m) y columnas = len(m[0]). Acceso: m[1][2] lee y m[0][3] = 9 escribe.

Con un tamaño fijo

Cada fila se crea por separado, dentro de un for.

¡Cuidado!

m = [[0] * 4] * 3 no sirve: las 3 filas serían la misma lista y al modificar una se modificarían todas. Por eso cada fila se crea por separado dentro del for. Míralo en la memoria: las tres filas cambian a la vez.

  • Pida al jugador una fila y una columna, y coloque una "X" en esa casilla.
  • Coloque una "O" en la esquina superior derecha usando el índice directamente.

Resolución

Recorrido de matrices (doble for)

Para visitar todos los elementos se usan dos for anidados: el externo recorre las filas y, por cada fila, el interno recorre todas sus columnas.

  • len(m) = número de filas; len(m[0]) = número de columnas.
  • end=" " evita el salto de línea entre elementos de una misma fila.
  • El print() final, fuera del for interno, salta de línea al terminar cada fila.

Total de iteraciones del for interno: filas × columnas = 2 × 3 = 6. Con f = 0 el interno recorre c = 0, 1, 2 y muestra la fila 0; luego vuelve a empezar en c = 0 para la fila 1.

Recorrido de una fila (un for)

Si solo nos interesa una fila, dejamos fijo el índice de la fila y recorremos sus columnas con un solo for. Es como recorrer un vector: m[f]. Para recorrer una columna se fija c y se recorre f.

7Inserción y eliminación

Sin append ni remove: con tamaño fijo y una variable cantidad.

Vectores de tamaño fijo

Como el tamaño no cambia, el vector tiene una capacidad (su tamaño) y llevamos en una variable cuántas posiciones están ocupadas.

v = [8, 3, 5, 9, 0, 0] y cantidad = 4

  • len(v) es la capacidad: 6 posiciones, siempre.
  • cantidad indica cuántas tienen datos válidos: 4.
  • Insertar y eliminar no cambian el tamaño: escriben o desplazan elementos y actualizan cantidad.

Inserción al final

Es el caso más simple: el nuevo valor se escribe en la primera posición libre, que es justamente v[cantidad]. No hay que mover ningún elemento.

  • Verificar que quede espacio (cantidad < len(v)).
  • Escribir el valor en v[cantidad].
  • Sumar 1 a cantidad.

cantidad < len(v) revisa que quede al menos una posición libre; así reemplazamos a append respetando el tamaño fijo.

Inserción entre elementos

Ahora el valor debe quedar en una posición ocupada (pos), sin perder los que ya estaban. Los elementos desde pos se corren a la derecha para dejarle espacio.

  • Verificar que quede espacio (cantidad < len(v)).
  • Correr a la derecha los elementos desde el final hasta pos.
  • Escribir el valor en pos y sumar 1 a cantidad.

Se recorre desde el final hacia pos, para no sobrescribir valores que aún no se movieron. range(cantidad, pos, -1) recorre hacia atrás: 4, 3, 2.

¿Qué es eliminar?

Eliminar es quitar el valor de una posición. Como el tamaño es fijo, no se borra la casilla: los elementos siguientes se corren a la izquierda para tapar el hueco.

  • Correr a la izquierda los elementos que están después de pos.
  • Restar 1 a cantidad.
  • Limpiar la última posición que quedó repetida (v[cantidad] = 0).

range(pos, cantidad - 1) recorre hacia adelante: 1, 2, 3. Para eliminar un valor (no una posición), primero se busca con búsqueda secuencial.

8Vectores paralelos

Varios vectores del mismo tamaño que describen a un mismo elemento, como si fueran objetos.

Son varios vectores del mismo tamaño en los que una misma posición describe a un mismo elemento. Cada vector representa un atributo.

pos 0pos 1pos 2pos 3
nombresAnaLuisSofíaPedro
edades19212022
notas6.14.55.83.9

Posición 1: Luis, 21 años, nota 4.5.

Regla de oro: si se mueve un elemento en un vector, hay que moverlo en todos

Creación y despliegue

  • Un solo for recorre los tres vectores a la vez, porque comparten el índice i.
  • len(nombres) sirve para todos: tienen el mismo tamaño.

Operaciones

Buscar al mejor estudiante

  • Se busca en el vector notas, pero se guarda la posición.
  • Con esa posición se obtiene el nombre: nombres[pos_mejor].

Intercambiar al ordenar

  • Al ordenar por nota, se compara notas, pero se intercambia en todos los vectores.
  • Si no, cada nota quedaría asociada a otro estudiante.
